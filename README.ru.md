# Northshell

Бесплатная альтернатива MobaXterm для macOS с открытым кодом: SSH-клиент и терминал с SFTP-браузером, встроенным редактором файлов на сервере и мониторингом нагрузки в одном окне.

## Зачем

MobaXterm — популярный SSH-инструмент «всё в одном», но он есть только под Windows. Northshell переносит тот же подход на Mac: открываете сессию, и рядом с терминалом появляются файлы сервера, а внизу — его нагрузка. Можно поправить конфиг прямо на сервере, скачать бэкап, проверить место на диске — не переключаясь между программами и ничего не устанавливая на сервер.

## Возможности

**Терминал**
- Локальный шелл и SSH-сессии во вкладках на xterm.js: GPU-отрисовка, truecolor, полноценный Unicode и кириллица.
- Поиск по выводу, кликабельные ссылки, копирование при выделении и вставка правой кнопкой (по желанию).
- Ввод сразу во все подключённые вкладки (MultiExec), переподключение одним кликом.
- Подсветка вывода как в MobaXterm (IP-адреса, ссылки, `error` / `warning` / `ok`) и информационная рамка при подключении — включаются в настройках.

**Сессии и аутентификация**
- Сессии с папками, цветными метками и поиском; импорт из `~/.ssh/config` одной кнопкой.
- Быстрое подключение строкой `user@host:port` или `ssh -p 2222 user@host`.
- Пароль, приватный ключ (с паролем), ssh-agent, keyboard-interactive / 2FA.
- Пароли хранятся зашифрованными в связке ключей macOS и не показываются в интерфейсе.
- Ключ сервера проверяется при каждом подключении (отпечаток SHA-256, предупреждение при смене).

**Библиотека команд**
- Частые команды сохраняются один раз и запускаются двойным кликом из боковой панели (`⇧⌘L`) или из палитры (`⌘P`).
- Команды бывают **общие** (во всех подключениях) и **частные** — только для одного подключения; «Выполнить» нажимает Enter, «Вставить» только набирает команду.
- Параметры: `{{id}}` или `{{limit:20}}` — значение спрашивается перед запуском.
- Всё хранится в обычном файле `commands.json`: его можно править руками, изменения сразу видны в приложении; импорт и экспорт — чтобы перенести библиотеку на другой Mac или поделиться с коллегами.

**HTTP-окружения (curl)**
- Тип подключения для API без SSH: локальный терминал, подготовленный для однотипных `curl`-запросов к одному серверу.
- В шелле заданы `$BASE_URL` и `$TOKEN` (токен хранится в связке ключей), а ваши заголовки (например, `Authorization: Bearer $TOKEN`) автоматически добавляются к каждому `curl`.
- `curl -k` для self-signed сертификатов по желанию; типовые запросы окружения — в его разделе библиотеки команд.

**SFTP и редактор файлов**
- Панель файлов рядом с терминалом: путь «хлебными крошками», сортировка по имени, размеру и дате, изменяемая ширина.
- Фильтр по текущей папке и рекурсивный поиск на сервере.
- Встроенный редактор с подсветкой около 20 языков; `⌘S` сохраняет файл прямо на сервер и предупреждает, если файл успели изменить.
- Загрузка перетаскиванием из Finder, очередь скачиваний, создание, переименование, удаление, права доступа (chmod).

**Мониторинг сервера**
- Нижняя строка: CPU, память, диск, сеть, нагрузка, аптайм и пользователи активного подключения.
- Панель мониторинга (`⇧⌘M`): графики CPU, памяти и сети, все диски, swap, топ процессов.
- Ничего не нужно ставить на сервер: данные читаются по тому же SSH-соединению (Linux и macOS).

**Внешний вид**
- Шесть тем: тёмная, светлая, системная, Visual Studio, MobaXterm и Windows 95.
- Девять цветовых схем терминала, настройка шрифта, курсора и буфера; интерфейс на русском и английском.

## Установка

**Требования:** macOS 13 Ventura или новее, Mac на Apple Silicon (M1–M4).

**Скачать:** [download/Northshell-1.4.0-arm64.dmg](download/) (около 112 МБ) или из [последнего релиза](https://github.com/nikserbur/northshell/releases/latest). Контрольная сумма — в [download/SHA256SUMS.txt](download/SHA256SUMS.txt):

```bash
shasum -a 256 ~/Downloads/Northshell-1.4.0-arm64.dmg
```

**Установка**
1. Откройте скачанный `Northshell-1.4.0-arm64.dmg`.
2. Перетащите **Northshell** в папку **Applications** в открывшемся окне.
3. Извлеките образ диска (`⌘E` в Finder).
4. Запустите Northshell из Applications, Launchpad или Spotlight.

<img src="docs/screenshots/install-dmg.png" width="560" alt="Перетащите Northshell в Applications" />

**Первый запуск.** Приложение не подписано платным сертификатом Apple, поэтому macOS блокирует первый запуск скачанной копии. Разрешите его один раз любым способом:

- **macOS 15 Sequoia и новее:** откройте Northshell, закройте предупреждение, затем **Системные настройки → Конфиденциальность и безопасность** → внизу сообщение о Northshell → **Всё равно открыть**, подтвердите паролем.
- **macOS 13–14:** в Finder нажмите на Northshell правой кнопкой (или с Control) → **Открыть** → **Открыть**.
- **Любая версия, через Терминал:**

  ```bash
  xattr -dr com.apple.quarantine /Applications/Northshell.app
  ```

При первом сохранении пароля macOS спросит, можно ли Northshell использовать объект связки ключей **Northshell Safe Storage** — выберите **Всегда разрешать**. После установки новой версии вопрос может повториться.

**Обновление:** скачайте новый DMG и снова перетащите Northshell в Applications с заменой. Сессии, настройки и известные хосты сохранятся.

**Удаление:** удалите приложение из Applications, папку `~/Library/Application Support/Northshell` и, при желании, объект **Northshell Safe Storage** в «Связке ключей».

## Начало работы

1. **Быстрое подключение:** на стартовом экране введите `user@host` (или `ssh -p 2222 user@host`) и нажмите Enter.
2. **Сохранить сессию:** `⌘N`, укажите хост, пользователя и способ входа, нажмите **Сохранить и подключиться**.
3. **Импорт хостов:** кнопка **ssh config** внизу боковой панели переносит записи из `~/.ssh/config`.
4. **Подтвердите ключ сервера:** при первом подключении сравните отпечаток с данными хостинга или с выводом `ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub` на сервере.
5. **Файлы:** перетащите файлы из Finder на SFTP-панель, двойной клик открывает файл в редакторе, `⌘S` сохраняет. Enter в поле фильтра ищет по всем вложенным папкам.
6. **Мониторинг:** нижняя строка показывает нагрузку; клик или `⇧⌘M` открывает подробную панель.
7. **Частые команды:** `⇧⌘L` открывает библиотеку команд, **+** добавляет команду — общую или для одного подключения. Двойной клик выполняет её.
8. **HTTP API:** кнопка **HTTP** внизу боковой панели (или `⌥⌘N`), укажите базовый URL, токен и заголовки, **Сохранить и открыть**. В терминале: `curl $BASE_URL/health` — заголовки подставятся сами.
9. **Оформление:** **Настройки → Внешний вид** (`⌘,`).

## Безопасность

- Ключ сервера проверяется при каждом подключении; при смене ключа подключение блокируется до вашего решения.
- Пароли шифруются через Electron `safeStorage` (связка ключей macOS) и не передаются в интерфейс.
- Интерфейс работает в песочнице с изоляцией контекста и строгой CSP; все запросы к основному процессу проверяются.
- Команды мониторинга и поиска на сервере — фиксированные скрипты с экранированием аргументов; поиск сам останавливается через 13 секунд.
- SFTP не перезаписывает существующие файлы при скачивании и не трогает цель при удалении символической ссылки.
- HTTP-окружения кладут заголовки для curl во временную папку с доступом только для владельца; она удаляется при закрытии вкладки.

Данные приложения: `~/Library/Application Support/Northshell/` (`sessions.json`, `commands.json`, `settings.json`, `known_hosts.json`).

## Northshell и другие SSH-клиенты для Mac

Tabby, Electerm и WindTerm — кроссплатформенные терминалы с SSH и SFTP. Termius и Royal TSX — коммерческие менеджеры подключений. iTerm2 — отличный терминал без передачи файлов, а Cyberduck, Transmit и ForkLift работают с файлами, но без терминала.

Northshell сделан под привычный по MobaXterm сценарий на macOS: SFTP-браузер рядом с терминалом той же сессии, редактирование файлов на сервере с сохранением по `⌘S`, мониторинг сервера без агентов, бесплатно и с открытым кодом, пароли в связке ключей macOS.

## Частые вопросы

**Есть ли MobaXterm для Mac?**
Сам MobaXterm работает только в Windows. Northshell — приложение для macOS с той же идеей: SSH-терминал, SFTP и мониторинг в одном окне. X11-сервера и Windows-утилит MobaXterm в нём нет.

**Это бесплатно?**
Да, открытый код под лицензией MIT, без аккаунтов, подписок и телеметрии.

**Работает ли на Intel?**
Готовая сборка — для Apple Silicon. На Intel можно собрать из исходников.

**Нужно ли что-то ставить на сервер?**
Нет. Мониторинг использует стандартные команды по тому же SSH-соединению, SFTP — стандартный `sftp-server` из OpenSSH.

**Где хранятся пароли?**
В зашифрованном виде в связке ключей macOS на вашем Mac.

**Можно редактировать файлы на сервере?**
Да: двойной клик по файлу в SFTP-панели открывает редактор с подсветкой, `⌘S` сохраняет файл на сервер (до 5 МБ).

## Ограничения

- Только сборка для Apple Silicon, без подписи и нотаризации Apple.
- Пока нет X11-проброса, RDP, VNC, последовательных портов, проброса портов и jump-хостов.
- Мониторинг поддерживает серверы на Linux и macOS; на системах только с BusyBox часть данных может отсутствовать.

## Сборка из исходников

Нужны macOS, Node.js 22+ и Xcode Command Line Tools.

```bash
git clone https://github.com/nikserbur/northshell.git
cd northshell
npm install
npm run dev      # запуск с hot reload
npm test         # unit-тесты
npm run dist     # DMG в папку dist/
```

E2E-тесты на Playwright: `npm run build && npm run e2e` (для SSH-сценариев задайте `XMT_E2E_SSH_HOST`, `XMT_E2E_SSH_PORT`, `XMT_E2E_SSH_USER`, `XMT_E2E_SSH_KEY`).
